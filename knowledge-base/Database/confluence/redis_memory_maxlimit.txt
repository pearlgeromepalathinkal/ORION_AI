Title: Redis Memory Eviction Policy Configuration
Source: Confluence
Domain: Database
Freshness: 0.9
Authority: 0.93
Reliability: 0.88
Content:
If Redis returns 'OOM command not allowed when used memory > maxmemory':
1. Set maxmemory-policy to volatile-lru or allkeys-lru in redis.conf.
2. Audit key TTL expiration times.
3. Cluster or upscale Redis memory size.
