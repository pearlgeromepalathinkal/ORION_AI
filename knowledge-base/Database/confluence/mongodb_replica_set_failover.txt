Content:
Handling MongoDB primary node failover:
1. Secondary node automatically elected primary within 10 seconds.
2. Ensure connection string specifies replicaSet parameter: mongodb://node1,node2/?replicaSet=rs0.
3. Verify write concern is set to w:majority.
