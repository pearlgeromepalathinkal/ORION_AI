Title: Linux Root Filesystem Disk Space Cleanup
Source: Confluence
Domain: Server
Freshness: 0.95
Authority: 0.98
Reliability: 0.93
Content:
If Linux server filesystem reaches 100% disk usage:
1. Identify large files: du -ah / | sort -rh | head -n 20.
2. Safely truncate log files: > /var/log/nginx/access.log.
3. Remove old journal logs: journalctl --vacuum-time=3d.
4. Clean package cache: apt-get clean or yum clean all.
