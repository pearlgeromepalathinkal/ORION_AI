Title: DBeaver JDBC Driver Download Error
Source: Github
Domain: Software
Freshness: 0.83
Authority: 0.86
Reliability: 0.83
Content:
If DBeaver fails to download PostgreSQL / MySQL JDBC driver behind corporate proxy:
1. Preferences -> Connections -> Driver Manager.
2. Set Network Proxy settings to HTTP Proxy: http://proxy.corp:8080.
3. Or manually import downloaded .jar file under Driver Properties.
