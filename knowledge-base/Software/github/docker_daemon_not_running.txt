Title: Docker Desktop Startup Failure
Source: Github
Domain: Software
Freshness: 0.92
Authority: 0.9
Reliability: 0.88
Content:
If Docker CLI displays 'Cannot connect to Docker daemon':
1. Open Docker Desktop application and wait for Engine Running.
2. On macOS, ensure socket link exists: sudo ln -s ~/.docker/run/docker.sock /var/run/docker.sock.
3. On Windows, ensure WSL 2 backend is enabled.
