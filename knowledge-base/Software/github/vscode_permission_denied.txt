Title: VS Code Installation Permission Fix
Source: Github
Domain: Software
Freshness: 0.9
Authority: 0.88
Reliability: 0.85
Content:
If installing VS Code extensions or updates fails with Permission Denied:
1. Use User Installer instead of System Installer.
2. Install to %LocalAppData%\Programs\Microsoft VS Code.
3. If extension folder permission error occurs, run: chown -R $USER ~/.vscode.
