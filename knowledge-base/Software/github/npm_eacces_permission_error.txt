Fixing npm install -g permission denied errors:
1. Do NOT use sudo npm install -g.
2. Reconfigure npm default directory: mkdir ~/.npm-global && npm config set prefix '~/.npm-global'
3. Add export PATH=~/.npm-global/bin:$PATH to ~/.zshrc.
