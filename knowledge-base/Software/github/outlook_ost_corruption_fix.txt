Source: Github

Freshness: 0.89

Content:
If Microsoft Outlook fails to sync email or crashes at startup:
1. Close Outlook.
2. Navigate to %LocalAppData%\Microsoft\Outlook.
3. Rename corrupted .ost file to .ost.old.
4. Restart Outlook to rebuild clean mailbox cache.
