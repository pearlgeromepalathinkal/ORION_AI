Source: Github

Freshness: 0.85

Content:
If PowerShell blocks virtualenv activation script:
1. Open PowerShell as Administrator.
2. Run command: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser.
3. Re-run: .\venv\Scripts\Activate.ps1.
