Content:
If Slack desktop client crashes or displays blank white window:
1. Open Slack -> Help -> Troubleshooting -> Clear Cache and Restart.
2. Disable Hardware Acceleration in Slack preferences if screen flickers.
3. Alternatively use Slack web app.
