Managing Cloudflare DNS updates:
1. Cloudflare DNS updates propagate globally in under 30 seconds.
2. If old IP persists, purge Cloudflare edge cache or test with dig @1.1.1.1 domain.com.
3. Verify Proxy status (orange cloud) settings.
