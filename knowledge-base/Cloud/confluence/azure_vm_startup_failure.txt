Title: Azure Virtual Machine Allocation Failure
Source: Confluence
Domain: Cloud
Freshness: 0.89
Authority: 0.92
Reliability: 0.88
Content:
If Azure VM fails to start with AllocationFailed error:
1. Deallocate VM completely in Azure Portal.
2. Wait 2 minutes and retry startup to trigger re-allocation to fresh compute cluster.
3. Change VM size if regional capacity is constrained.
