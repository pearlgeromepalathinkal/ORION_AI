Title: MFA Authenticator Re-registration Process
Source: Sharepoint
Domain: Security
Freshness: 0.92
Authority: 0.96
Reliability: 0.9
Content:
If user loses phone or replaces MFA device:
1. User identity must be verified via manager video call or HR portal.
2. Service desk generates a temporary 8-hour Passcode.
3. User registers new device at https://aka.ms/mfasetup.
