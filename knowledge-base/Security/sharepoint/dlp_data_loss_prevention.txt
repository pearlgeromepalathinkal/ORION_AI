Title: Data Loss Prevention DLP Violation Handling
Source: Sharepoint
Domain: Security
Freshness: 0.9
Authority: 0.94
Reliability: 0.89
Content:
When sensitive data transfer (SSN, credit card, source code) is blocked:
1. DLP agent generates notification alert to user and manager.
2. To request business justification override, submit DLP ticket.
3. Repeated policy violations result in HR escalation.
