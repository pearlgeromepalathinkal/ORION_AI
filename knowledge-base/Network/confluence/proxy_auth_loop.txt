If browser repeatedly prompts for proxy credentials:
1. Ensure Windows Internet Settings use automatic PAC script: http://wpad.corp/wpad.dat.
2. Clear stored credentials in Windows Credential Manager under Generic Credentials.
3. Restart browser and log in with domain credentials.
